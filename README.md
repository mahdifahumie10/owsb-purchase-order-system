# OWSB Purchase Order Management System  

A simple purchase order management system developed as a university project in collaboration with group mates.
The system handles suppliers, purchase requests, purchase orders, sales, inventory, and payments.  

## Features
- Supplier management  
- Purchase request & purchase order tracking  
- Inventory management  
- Sales recording  
- Payment processing  
- File-based storage system (`.txt` files for data)  
- Basic UI built using Java Swing (JFrame)  

##  Technologies Used
- **Language:** Java  
- **IDE:** Apache NetBeans  
- **Data Storage:** Text files (CSV-style format)  
##  How to Download

## How to Run:
- Extract the zip file
- Open Apache Netbeans IDE 25 -> Open Project
- Open the owsb-purchase-order-system-main folder -> select owsb and open it in Netbeans
- Run the program. Usernames and passwords can be found in the users.txt file uploaded above
